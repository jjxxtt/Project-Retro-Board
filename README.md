# 项目过程记录与复盘台 (Project Retro Board)

一个**零依赖、单文件、纯本地**的项目过程记录与复盘工具。双击即用，数据存在浏览器本地，不联网、不依赖任何后端或第三方服务。

> 适合个人或小团队做项目过程留痕、问题/风险跟踪与复盘沉淀。

## ✨ 特性

- **单文件运行**：整个应用就是一个 `index.html`（内嵌 CSS + JS），无需安装、无需构建、完全离线。
- **多项目管理**：左侧栏新建 / 切换 / 删除项目，每个项目独立记录与复盘。
- **总览 + 下钻**：首屏 Dashboard 总览一眼看到关键指标，点「查看全部」下钻到全量列表。
  - 顶部 KPI：项目进度、待处理/进行中、已解决、里程碑、经验沉淀数
  - **需要关注**：未完成的问题/风险，按严重度排序
  - **最近动态**：最新时间线
  - **经验沉淀**：最近的经验教训
- **四大记录维度**
  - 📌 时间线 / 里程碑（日期、类型、说明、交付物）
  - 🐞 问题 / 风险（状态、严重度、负责人、创建/解决日期、筛选与搜索）
  - 💡 经验教训（分类、标签、正文）
  - 📊 数据看板（进度、解决率、状态/严重度分布）
- **轻量录入**：列表页常驻快速添加条（填标题回车即建，可连续录入）+ 卡片内联编辑，无需弹框。
- **数据安全**：浏览器 `localStorage` 实时保存，支持一键 **导出 / 导入 JSON** 备份，换电脑直接带走。
- **明暗主题**：内置浅色 / 深色切换。

## 🚀 快速开始

1. 下载本仓库，进入 `project-retro/` 目录。
2. 双击 `index.html` 用浏览器打开（推荐 Chrome / Edge / Firefox）。
3. 首次打开会自动生成一个「示例项目：1P64S 刀片电池 Pack」演示数据，删掉即可建自己的项目。

> 提示：数据保存在当前浏览器的 `localStorage` 中。清理浏览器数据会丢失记录，建议定期用侧栏「导出」按钮备份 JSON。

## 📁 目录结构

```
project-retro/
├── index.html   # 应用本体（单文件，含全部 HTML/CSS/JS）
└── README.md
```

## 💾 数据存储

| 方式 | 说明 |
| --- | --- |
| 自动保存 | 所有改动实时写入浏览器 `localStorage`（键名 `retro_app_v1`） |
| 导出 | 侧栏「导出」生成 `复盘台数据_YYYY-MM-DD.json` |
| 导入 | 侧栏「导入」读取 JSON 文件恢复（会覆盖当前数据，建议先备份） |

## 🛠 技术栈

- 原生 HTML / CSS / JavaScript（ES5+），无任何框架、打包器或 CDN 依赖。
- 存储：`localStorage` + JSON 文件导入导出。
